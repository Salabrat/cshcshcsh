# 📂 Фикс: раздел каталога с пустым описанием «отправлял 2 стикера и всё»

## Симптом

Создали новую тему → при открытии бот присылает **два стикера и ничего больше**
(ни текста, ни кнопок с категориями).

Проверка по базе показала масштаб: из 15471 элемента каталога **149 имеют пустое
описание**, и все они вели себя так же.

---

## Корневая причина

Telegram **не принимает сообщение с пустым текстом**:

```
Bad Request: message text is empty
```

Цепочка в коде:

1. Открывается раздел с пустым описанием:

```python
description = format_description_with_preview(theme[4], theme[7])   # → ""
```

2. Раньше функция возвращала пустую строку:

```python
if not preview_link ...:
    return description or ""        # ← пустая строка
```

3. Дальше вызывался `replace_message_with_sticker_first(new_text="", sticker_id=...)`:

```python
if sticker_id:
    await bot.send_sticker(...)          # 1-й стикер — успешно
...
await bot.send_message(text=new_text)    # text="" → ОШИБКА Telegram
```

4. Срабатывал блок обработки ошибки внутри той же функции, который **дублировал
   отправку стикера**, а сообщение с текстом снова падало:

```python
except Exception as e:
    try:
        if sticker_id:
            await bot.send_sticker(...)  # 2-й стикер — вот он!
        ...
        await bot.send_message(text=new_text)  # снова "" → снова ошибка
```

Итог для пользователя: **2 стикера, ни текста, ни кнопок**. Функция молча
проглатывала ошибку (`except` + `print`), поэтому в логах ничего заметного не было.

Дополнительно: кнопка «🏪 Каталог товаров» отправляла сообщение с
`caption=""`/`text=""` — то же самое для каталога без фото.

---

## Что исправлено

### 1. `format_description_with_preview` больше никогда не возвращает пустую строку

Добавлен параметр `fallback` и глобальный дефолт `DEFAULT_SECTION_TEXT`:

```python
DEFAULT_SECTION_TEXT = "📂 Выберите раздел:"

def format_description_with_preview(description, preview_link=None, fallback=None):
    text = str(description).strip() if description is not None else ""
    if text.lower() == "none":
        text = ""
    if not text:
        text = fallback or DEFAULT_SECTION_TEXT
    ...
```

### 2. Осмысленный текст-заглушка для каждого раздела

Пустая строка заменяется названием раздела — пользователь всегда понимает, где он:

| Раздел | Что показывается при пустом описании |
|---|---|
| Тема | `🏪 <b>Название темы</b>` + «Выберите категорию:» |
| Категория | `📂 <b>Название</b>` + «Выберите раздел:» |
| Подкатегория | `📂 <b>Название</b>` + «Выберите товар:» |
| Товар | `📦 <b>Название</b>` |
| Кнопка «Каталог» | `🏪 <b>Каталог товаров</b>` + «Выберите тему:» |

### 3. `replace_message_with_sticker_first` — защита от двойного стикера

* текст гарантированно непустой (`DEFAULT_SECTION_TEXT` как последний рубеж);
* стикер **больше не отправляется повторно** в блоке обработки ошибки —
  добавлен флаг `sticker_sent`.

## Важно знать

- **Исправлять данные в базе не нужно** — заглушка подставляется на лету, все
  149 разделов с пустым описанием сразу начнут открываться.
- Если хотите свой текст вместо авто-заглушки — задайте описание у раздела через
  «Изменить категорию/тему → Описание» (форма уже починена, см. `EDIT_FORMS_FIX.md`).
- После правок нужен **перезапуск бота**.
