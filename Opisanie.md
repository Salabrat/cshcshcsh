# 🛍 StreetSoft Katalog — описание проекта

> **Telegram-магазин под ключ**: продажа цифровых товаров и доступов прямо в чате + полноценная
> витрина в Telegram Mini App. Бот одновременно является **магазином для клиента**,
> **CMS для владельца** (каталог, цены, медиа, реквизиты, промокоды) и
> **админ-панелью** (заказы, платежи, рассылки, поддержка, статистика).

Бот: `@testshoptestshopbot` · стек: **Python 3.10 + aiogram 2.25 + SQLite (aiosqlite)** ·
идентификатор проекта в коде: `SALIKSDELALMILLION`.

---

## 🎯 Зачем нужен этот бот

| Проблема продавца | Как решает бот |
|---|---|
| Продажа цифровых товаров «вручную» в ЛС | Автоматический каталог, заказы и выдача файлов |
| Много платёжек, непонятно, кто оплатил | 7 способов оплаты + автопроверка статусов |
| Нужно вручную выдавать доступ на N дней | Файлы с периодами (7/30/90 дней) и сроком действия заказа |
| Нет учёта клиентов и повторных продаж | Баланс, бонусы, билеты, реферальная программа, рассылки |
| Настройки приходится менять в коде | Полностью редактируется из бота: тексты, кнопки, каталог, реквизиты |
| Клиенты пишут «не работает» в личку | Встроенная служба поддержки с обращениями и ответами оператора |
| Нужен «магазин как приложение» | Telegram Mini App с каталогом, корзиной, избранным и профилем |

## 🧭 Структура витрины

Каталог — это **дерево из 4 уровней**, которое админ собирает сам:

```
🏪 Каталог товаров
├── Тема          (например: VPN, Аккаунты, Подписки)
│   ├── Категория
│   │   ├── Подкатегория
│   │   └── Товар      ← тут цена, описание, медиа, файлы выдачи
```

Возможности витрины:

- **Сетка 3×6** с пагинацией и «плитками» вместо длинных списков;
- **Поиск** по каталогу — локальный (внутри раздела) и **глобальный** по всей базе;
- **Медиа у каждого элемента**: фото, стикер, GIF, видео;
- **Превью-ссылка** для категории/темы/подкатегории (куда ведёт кнопка);
- **Выравнивание кнопок** — 1, 2 или 3 кнопки в ряду (для каждого раздела отдельно);
- **Описание** и **название** редактируются из бота, без правки кода;
- **Мультимедиа-группы**: можно залить сразу альбом файлов — бот их соберёт и обработает;
- **Умная очистка сообщений**: бот сам убирает «мусор» в чате при навигации.

## 💳 Оплата: 7 способов в одном окне

Методы хранятся в БД (`payment_methods`) и включаются/выключаются **и переставляются по сетке**
из админки (`payment_method_layout`) — ряд/позиция в ряду для каждого метода.

| Метод | Что это | Проверка оплаты |
|---|---|---|
| 📱 СБП по номеру | Перевод по номеру телефона | Вручную админом |
| 💳 Банковская карта | Перевод на карту / оплата через провайдера | Вручную админом / Telegram Payments |
| ₿ Криптовалюта | Реквизиты в крипте | Вручную админом |
| ⭐ Telegram Stars | Нативные платежи Telegram | Инвойс + автоматический `successful_payment` |
| 🤖 CryptoBot | Оплата через @CryptoBot | **Автопроверка** (`check_cryptobot_payments`) |
| 🌐 BitPapa | Оплата через BitPAPA API | **Автопроверка** статуса платежа |
| 🎮 Скинами | Оплата игровыми предметами | Вручную админом |

Дополнительно:

- **Инвойсы Telegram** (`createInvoiceLink`, `send_invoice`, `answer_pre_checkout_query`) —
  с поддержкой провайдер-токена для карт и отдельного канала для Stars;
- **Промокоды**: глобальные (админ создаёт `/promo КОД СКИДКА`) и **на конкретный товар**
  (`product_promo_codes`);
- **Срок оплаты 20 минут** — по истечении бот сам меняет статус и присылает клиенту
  сообщение с контактами платёжной системы;
- **Ручное подтверждение** платежа админом прямо из чата (approve/reject по заявке);
- **Отмена заказа** клиентом и админом, возврат в исходное состояние (`restore_order`).

## 📦 Покупки, заказы и выдача

- Выбор **количества** и **срока действия** (7/30/90 дней) — цена считается по тарифу
  (`product_prices`, `product_files` с `day_period`);
- **Мои заказы** с пагинацией, детальной карточкой и статусами
  (`pending / paid / expired / cancelled`);
- **Автоматическая выдача файлов** после оплаты, с учётом количества и периода;
- **Таймеры и фоновые задачи**: `check_expired_payments`, `check_order_expiration`,
  `check_cryptobot_payments` — бот сам следит за сроками и уведомляет;
- **Кнопка «Поделиться»** — генерация ссылки на товар (диплинк) и открытие товара по ссылке;
- **Избранное** и **корзина** — работают и в боте, и в Mini App;
- **История транзакций** (`transactions`) — пополнения, покупки, выводы, бонусы.

## 💰 Баланс, реферальная программа, вывод средств

- **Личный профиль**: ID, дата регистрации, основной и партнёрский баланс, статистика покупок;
- **Пополнение баланса**: фильтр ввода (минимум 50 ₽), выбор суммы или своя сумма
  (`custom_amount`), повторный заход «назад к пополнению»;
- **Оплата покупок с баланса** — в один клик, без внешних платёжек;
- **Реферальная программа**: у каждого своя ссылка, партнёрский баланс,
  статистика приглашённых;
- **Вывод средств**: заявка на вывод на баланс или внешним способом — с обработкой админом.

## 🎁 Бонусная система (геймификация)

Экономика удержания клиента — **билеты** за выполненные задания:

- **Категории бонусов** (`bonus_sections`) — дерево разделов с фото, стикером и описанием;
- **4 типа заданий** (`bonus_tasks`):
  1. 💰 **Покупки на сумму** — «купи на 1500 ₽»;
  2. 👥 **Пригласи друзей** — «приведи N друзей»;
  3. 🛋 **Купить товар** — «купи конкретный товар»;
  4. ⚙️ **Произвольное задание** — свободное условие;
- **Прогресс пользователя** (`user_task_progress`) — что выполнено, что в процессе;
- **Кнопки «Проверить задание» / «Я выполнил»** с серверной проверкой условия
  (по покупкам, рефералам, факту заказа);
- **Настраиваемый блок «🎁ПОЛУЧИ БОНУСЫ🎁»**: стикер, фото, описание, категории — всё из админки.

## 🆘 Служба поддержки

- Клиент выбирает **тему обращения** (список тем редактируемый) и пишет сообщение;
- Обращение сохраняется в `tickets`, админ получает уведомление с кнопкой **«✉️ Ответить»**;
- Оператор представляется (имя оператора), пишет ответ **(с сохранением HTML-форматирования)**;
- Клиент получает ответ отдельным уведомлением, история обращений доступна в разделе;
- **Все обращения** — список для админа, просмотр и продолжение диалога.

## 📱 Telegram Mini App (витрина-приложение)

Полноценный магазин внутри Telegram (`TGMiniapp.html` + `telegram-*.js`):

- **Нижняя навигация**: 🏠 Home · 🏪 Каталог · 🛒 Корзина · ❤️ Избранное · 👤 Профиль;
- **Каталог и категории** с ленивой подгрузкой, плитками и модальным окном товара;
- **Корзина и оформление заказа** (checkout) с выбором способа оплаты и количества;
- **Избранное** со счётчиком на иконке;
- **Профиль**: баланс, заказы, бонусы, рефералка;
- **Рулетка** (`telegram-roulette-page.js`) — игровая механика на билетах;
- **Fullscreen-просмотр изображений**, свайп товаров, экран загрузки, темы оформления;
- **Админ-страница Mini App** (`telegram-admin-page.js`) — рассылки, приветствие, статистика,
  работа с каталогом;
- **iOS-фиксы** и защита от «прыжков» интерфейса, адаптация под тёмную/светлую тему;
- Поддерживается запуск через **Menu Button** бота, URL задаётся в `config.MINIAPP_URL`.

## 🛠 Админ-панель (всё из чата)

| Команда | Что делает |
|---|---|
| `/start` | Главное меню |
| `/cards` | 💳 Управление реквизитами и платёжными методами |
| `/edit` | ✏️ Редактирование приветствия `/start` (стикер, фото, текст) |
| `/editbutton` | ✏️ Переименование кнопок главного меню |
| `/admins` | 👥 Состав администраторов: добавить/удалить, права |
| `/send` | 📢 Рассылка: всем или выбранным |
| `/promo` | 🎁 Управление промокодами |
| `/mmnt` | 📄 Выгрузка всех пользователей (username, ID, ФИО) файлом |
| `/tokens` | 🔑 Просмотр API-токенов (BitPAPA, Stars, CryptoBot) |
| `/set_token` | 🔑 Обновление токена платёжной системы |

**Редактор каталога** (кнопками, без кода): создание/удаление тем, категорий, подкатегорий и
товаров; загрузка фото/стикеров/GIF/видео и **файлов выдачи**; цены и тарифы по дням;
описания; превью-ссылки; выравнивание (1/2/3 кнопки в ряд); выбор сетки 3×6;
подтверждение отмены, чтобы не удалить лишнее.

**Рассылки**: текст, фото, документ, **инлайн-кнопки в сообщении**, отправка всем или по
списку ID, отложенный старт, подтверждение и отчёт (успешно/ошибки), рассылка конкретного товара.

**Управление платежами**: включение/отключение метода, порядок кнопок в сетке, изменение
реквизитов (СБП/карта/крипта/ссылки), своя раскладка платёжной страницы.

**Админы**: добавление по ID/username, удаление с подтверждением, защита главного админа,
команды и уведомления только для админов.

**Настройки без кода** (`bot_settings`, `button_names`): приветствие и его стикер/фото/текст,
описание бонусов, подписи кнопок меню, темы обращений, тексты платёжных страниц.

## 🛡 Надёжность (что специально предусмотрено)

- **Только один экземпляр бота** — `bot_manager.py` убивает дубли (иначе Telegram отдаёт
  апдейты «не тому» процессу и бот ведёт себя непредсказуемо);
- **Явный список `allowed_updates`** + автосброс при старте — инлайн-кнопки не могут
  «отвалиться» из-за залипшей настройки Telegram (см. `INLINE_BUTTONS_FIX.md`);
- **Обработчик ошибок** (`@dp.errors_handler`) и ретраи polling при сетевых сбоях;
- **Корректное завершение**: `on_shutdown`, закрытие storage и БД, обработка сигналов;
- **Диагностика в комплекте**: `check_bot.py` (webhook/`allowed_updates`),
  `check_inline_buttons.py` (аудит покрытия кнопок хендлерами),
  `_reset_allowed_updates.py` (ручной сброс);
- **Формы редактирования защищены от перехвата**: глобальный обработчик текста меню
  пропускает ввод, относящийся к активной форме (реестр из 70 FSM-состояний),
  регрессионный тест — `test_edit_forms.py` (см. `EDIT_FORMS_FIX.md`);
- **Разделы с пустым описанием открываются корректно**: вместо ошибки Telegram
  «message text is empty» подставляется название раздела, стикер отправляется
  один раз (см. `CATALOG_EMPTY_DESC_FIX.md`, тест `test_catalog_open.py`).

## ▶️ Быстрый старт

```powershell
# 1) Зависимости
python -m pip install -r requirements.txt

# 2) Запуск бота (с защитой от дублей)
python bot_manager.py start        # или: python streetshop.py

# 3) Плюс сервисы/логи/проверки
powershell -ExecutionPolicy Bypass -File .\run_all.ps1
powershell -ExecutionPolicy Bypass -File .\run_all.ps1 -Tunnel -UpdateConfig  # URL для Mini App

# 4) Диагностика
python check_bot.py
```
