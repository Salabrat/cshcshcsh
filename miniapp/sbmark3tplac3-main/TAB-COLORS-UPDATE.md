# ⚫⚪ Обновление цветов вкладок Mega Menu

## Что изменено

Обновлена цветовая схема вкладок SHOP mega menu для лучшей контрастности.

---

## 🎨 Новая цветовая схема

### Неактивная вкладка:
- **Фон:** `#fff` (белый) ⚪
- **Текст:** `#000` (черный)
- **Разделитель "+":** `#000` (черный)

### Активная вкладка:
- **Фон:** `#000` (черный) ⚫
- **Текст:** `#fff` (белый)
- **Разделитель "+":** `#fff` (белый)

### Hover на неактивной:
- **Фон:** `#f5f5f5` (светло-серый)
- **Текст:** `#000` (черный)

---

## 📋 CSS Изменения

### Раньше:

```css
.mega-menu-tabs {
    background-color: #1a1a1a;  /* Темный фон */
}

.mega-menu-tab {
    background: none;  /* Прозрачный */
    color: #666;  /* Серый текст */
}

.mega-menu-tab:hover {
    background-color: #222;
    color: #999;
}

.mega-menu-tab.active {
    background-color: #000;
    color: #fff;
}
```

### Теперь:

```css
.mega-menu-tabs {
    background-color: transparent;  /* Прозрачный фон */
}

.mega-menu-tab {
    background-color: #fff;  /* Белый фон ⚪ */
    color: #000;  /* Черный текст */
}

.mega-menu-tab:hover {
    background-color: #f5f5f5;  /* Светло-серый */
    color: #000;
}

.mega-menu-tab.active {
    background-color: #000;  /* Черный фон ⚫ */
    color: #fff;  /* Белый текст */
}

.mega-menu-tab.active:not(:last-child)::after {
    color: #fff;  /* Белый разделитель "+" */
}
```

```
│  ⚫ Черный "+"      │  ⚪ Белый "+"       │
│                    │                    │

```

|---------|--------------|-------------|

| **Неактивная вкладка фон** | `none` (прозрачный) | `#fff` ⚪ |
| **Неактивная вкладка текст** | `#666` (серый) | `#000` ⚫ |
| **Активная вкладка фон** | `#000` ⚫ | `#000` ⚫ |
| **Активная вкладка текст** | `#fff` ⚪ | `#fff` ⚪ |
| **Hover фон** | `#222` | `#f5f5f5` |
| **Разделитель "+"** | `#666` → `#fff` | `#000` → `#fff` |

- ✅ Черный текст (#000) - высокая контрастность

- ✅ Разделитель меняет цвет в зависимости от состояния

## 🔄 Что делать

### 1. Очистите кэш браузера:
```
Ctrl + Shift + Delete
```

### 2. Перезагрузите страницу:
```
Ctrl + Shift + R
```

### 3. Откройте SHOP menu:
- Кликните на **SHOP** в header
- Проверьте цвета вкладок

### 4. Результат:
- ⚪ MAIN COLLECTION: белый фон, черный текст (активная)
- ⚫ BRAND: белый фон, черный текст (неактивная)
- Кликните BRAND → черный фон, белый текст ✅
