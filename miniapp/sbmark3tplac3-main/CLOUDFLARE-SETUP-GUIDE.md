# 🚀 Пошаговая инструкция: Cloudflare Tunnel

## ✅ Шаг 1: Найдите URL в окне Cloudflare Tunnel

После запуска `start-cloudflare.bat` откроются **2 окна**:

1. **Окно сервера** (npm start) - показывает логи сервера
2. **Окно Cloudflare Tunnel** - показывает URL туннеля

### Где найти URL:

В окне **Cloudflare Tunnel** найдите строку, которая выглядит так:

```
+--------------------------------------------------------------------------------------------+
|  Your quick Tunnel has been created! Visit it at (it may take some time to be reachable):  |
|  https://random-name-1234.trycloudflare.com                                               |
+--------------------------------------------------------------------------------------------+
```

**Скопируйте URL** (например: `https://random-name-1234.trycloudflare.com`)

---

## ✅ Шаг 2: Создайте полный URL для Telegram Mini App

Добавьте к URL путь `/TGminiapp.html`:

**Пример:**
- URL туннеля: `https://random-name-1234.trycloudflare.com`
- Полный URL: `https://random-name-1234.trycloudflare.com/TGminiapp.html`

---

## ✅ Шаг 3: Обновите URL в BotFather

1. **Откройте Telegram** и найдите [@BotFather](https://t.me/BotFather)

2. **Отправьте команду:**
   ```
   /mybots
   ```

3. **Выберите вашего бота** из списка

4. **Выберите "Bot Settings"** (Настройки бота)

5. **Выберите "Menu Button"** (Кнопка меню)

6. **Когда спросит URL**, отправьте полный URL:
   ```
   https://random-name-1234.trycloudflare.com/TGminiapp.html
   ```
   (замените на ваш реальный URL)

7. **Готово!** BotFather подтвердит обновление

---

## ✅ Шаг 4: Проверьте работу

1. Откройте вашего бота в Telegram
2. Нажмите на кнопку меню (обычно внизу экрана)
3. Должна открыться ваша Mini App!

---

## 🔄 Альтернативный способ: Автоматический скрипт

Если хотите, чтобы URL автоматически извлекался и сохранялся:

### Вариант 1: Используйте Node.js скрипт
```bash
npm run cloudflare
```

Этот скрипт:
- ✅ Запустит сервер
- ✅ Запустит Cloudflare Tunnel
- ✅ Автоматически извлечет URL
- ✅ Сохранит его в файл `cloudflare-url.txt`

### Вариант 2: Проверьте файл cloudflare-url.txt

После запуска скрипта проверьте файл `cloudflare-url.txt` в папке проекта - там будет сохранен полный URL.

---

## ⚠️ Важные замечания

1. **URL меняется при каждом перезапуске** - после перезапуска Cloudflare Tunnel нужно обновить URL в BotFather

2. **Сервер должен быть запущен** - не закрывайте окна с сервером и туннелем

3. **Проверьте доступность** - откройте URL в браузере, чтобы убедиться, что туннель работает

---

## 🆘 Если что-то не работает

### Проблема: Не вижу URL в окне Cloudflare
- Подождите 10-15 секунд - туннелю нужно время для создания
- Проверьте, что cloudflared установлен правильно
- Перезапустите `start-cloudflare.bat`

### Проблема: URL не открывается в браузере
- Убедитесь, что сервер запущен (`npm start`)
- Проверьте, что порт 3002 свободен
- Попробуйте перезапустить туннель

### Проблема: Mini App не открывается в Telegram
- Проверьте, что URL правильный (должен заканчиваться на `/TGminiapp.html`)
- Убедитесь, что обновили URL в BotFather
- Попробуйте перезапустить бота в Telegram
