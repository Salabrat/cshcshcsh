# 🚀 Ручной запуск сервера и ngrok

## ❌ Проблема
Скрипт `npm run ngrok` не показывает URL от ngrok.

## ✅ Решение: Запуск вручную в двух терминалах

### Вариант 1: Через два окна терминала

**Терминал 1 - Сервер:**
```bash
npm start
```
Оставьте этот терминал открытым. Вы увидите:
```
Server running at http://localhost:3002
```

**Терминал 2 - ngrok:**
```bash
ngrok http 3002
```

Вы сразу увидите URL:
```
Forwarding  https://abc123.ngrok.io -> http://localhost:3002
```

### Вариант 2: Использовать готовый .bat файл

Просто запустите:
```bash
start-simple.bat
```

Он автоматически откроет два окна - сервер и ngrok.

## 📋 Что делать после запуска

1. **Скопируйте URL** из окна ngrok (например: `https://abc123.ngrok.io`)
2. **Добавьте путь к Mini App:**
   ```
   https://abc123.ngrok.io/TGminiapp.html
   ```
3. **Отправьте в BotFather** этот полный URL

## 🌐 Альтернатива: Веб-интерфейс ngrok

Даже если URL не виден в терминале, он всегда доступен в веб-интерфейсе:

Откройте в браузере:
```
http://127.0.0.1:4040
```

Там точно будет ваш ngrok URL!

## ✅ Проверка работы

1. Сервер должен быть доступен: `http://localhost:3002`
2. ngrok должен быть доступен: `http://127.0.0.1:4040`
3. В веб-интерфейсе ngrok будет виден ваш HTTPS URL

## 🎯 Рекомендация

Используйте **два отдельных терминала** - это самый надежный способ:
- Один терминал для сервера
- Один терминал для ngrok
- Все видно и понятно!
