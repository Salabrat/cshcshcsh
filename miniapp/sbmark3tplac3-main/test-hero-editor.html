🚀 Hero Editor Features

  • 📝
    Кнопка в левом нижнем углу: После входа как админ появится оранжевая кнопка "📝 Изменить Hero"
  • ✏️
    Редактирование заголовка: Можно изменить главный заголовок с поддержкой переносов строк
  • 📄
    Редактирование подзаголовка: Изменение описательного текста под заголовком
  • 🔘
    Текст кнопки: Изменение текста CTA кнопки
  • 🖼️
    Фоновое изображение: Загрузка нового фонового изображения для Hero секции
  • 💾
    Сохранение на сервер: Все изменения сохраняются и видны всем пользователям

📋 Инструкция

  1. Нажмите кнопку "Login as Admin" в правом верхнем углу
  2. Введите учетные данные (admin / admin123)
  3. После входа в левом нижнем углу hero секции появится кнопка "📝 Изменить Hero"
  4. Нажмите на нее для открытия модального окна редактирования
  5. Измените нужные поля и загрузите новое изображение при необходимости
  6. Нажмите "💾 Сохранить изменения"
  7. Обновите страницу, чтобы убедиться, что изменения сохранены
