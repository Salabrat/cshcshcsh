# Руководство по редактированию текста для администратора

## Быстрый старт

### Вход в режим администратора
1. **Быстрый способ**: Нажмите `Ctrl+Shift+A` на любой странице
2. **Через логин**: Войдите через страницу `/login.html` с правами администратора
3. После входа обновите страницу (F5)

### Редактирование текста
1. Наведите курсор на любой редактируемый текст
2. Появится кнопка редактирования (круглая с иконкой карандаша)
3. Нажмите на кнопку для открытия редактора
4. Внесите изменения
5. Нажмите "Сохранить" для применения изменений

## Редактируемые элементы

### Hero секция (главный баннер)
- **`.hero-title`** - Главный заголовок (поддерживает HTML теги, например `<br>` для переноса строки)
- **`.hero-subtitle`** - Подзаголовок

### Кампании (campaign sections)
- **`.campaign-label`** - Метка кампании (например, "FALL WINTER 025")
- **`.campaign-title`** - Заголовок кампании (поддерживает HTML)
- **`.campaign-description`** - Описание кампании

### О компании (about section)
- **`.about-title`** - Заголовок секции
- **`.about-text`** - Текст описания компании

## Особенности

### Поддержка HTML в заголовках
Заголовки (`.hero-title`, `.campaign-title`, `.about-title`) поддерживают HTML теги:
- `<br>` - перенос строки
- `<strong>` - жирный текст
- `<em>` - курсив

**Пример:**
```html
HIGH<br>PERFORMANCE<br>JACKETS
```

### Автосохранение
Все изменения автоматически сохраняются:
- На странице (мгновенно)
- В базе данных через API (если сервер запущен)

### Уведомления
После сохранения появляется уведомление:
- ✅ Зеленое - успешное сохранение
- ❌ Красное - ошибка (проверьте, запущен ли сервер)

## Тестирование

### Тестовая страница
Откройте `/test-admin-edit.html` для проверки функциональности:
1. Нажмите "Login as Admin"
2. Обновите страницу
3. Проверьте появление кнопок редактирования

### Проверка на главной странице
1. Откройте главную страницу `/index.html`
2. Нажмите `Ctrl+Shift+A` для входа в режим админа
3. Обновите страницу (F5)
4. Наведите на тексты - должны появиться кнопки редактирования

## Решение проблем

### Кнопки не появляются
1. Убедитесь, что вы вошли как администратор
2. Обновите страницу после входа
3. Проверьте консоль браузера (F12) на наличие ошибок

### Изменения не сохраняются
1. Проверьте, запущен ли сервер (`node server.js`)
2. Убедитесь, что сервер работает на порту 3002
3. Проверьте сетевые запросы в консоли разработчика

## Технические детали

### Файлы системы:
- `homepage-text-editor.js` - основной скрипт редактирования текстов (только для админов)
- `load-homepage-texts.js` - загрузка сохраненных текстов для всех пользователей
- `homepage-texts.json` - хранилище текстов

### API endpoints:
- `GET /api/homepage-texts` - получить текущие тексты
- `POST /api/homepage-texts` - сохранить обновленные тексты
