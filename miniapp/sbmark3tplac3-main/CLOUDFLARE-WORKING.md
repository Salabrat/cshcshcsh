2. ✅ Туннель подключен: `Registered tunnel connection`
3. ✅ Метрики работают: `Starting metrics server on 127.0.0.1:20241/metrics`

После подключения туннель работает **тихо** - он просто передает трафик. Новые сообщения появляются только при:
- Ошибках
- Переподключениях

**Это нормально!** Туннель работает, просто не выводит сообщения постоянно.
