# 🚀 Быстрый старт

## Запуск проекта за 30 секунд

### Вариант 1: Двойной клик (Самый простой)
1. Откройте папку `SITEcpcompany`
2. Дважды кликните на файл `index.html`
3. Сайт откроется в вашем браузере по умолчанию

### Вариант 2: Python HTTP Server (Рекомендуется)
```bash
# Перейдите в папку проекта
cd c:/Users/namename/Documents/SITEcpcompany

# Запустите сервер
python -m http.server 8000

# Откройте браузер
http://localhost:8000
```

### Вариант 3: VS Code Live Server
1. Откройте проект в VS Code
2. Установите расширение "Live Server"
3. Правый клик на `index.html` → "Open with Live Server"

### Вариант 4: Node.js (Для разработчиков)
```bash
# Установите зависимости (опционально)
npm install

# Запустите dev сервер
npm start

# Или используйте live-server
npm run dev
```

## 🔧 Настройка и кастомизация

### Изменить цвета
Откройте `styles.css` и измените переменные:
```css
:root {
    --primary-color: #000000;    /* Черный → Ваш цвет */
    --secondary-color: #ffffff;  /* Белый → Ваш цвет */
    --text-color: #333333;       /* Серый → Ваш цвет */
}
```

### Изменить скорость слайдера
Откройте `script.js` и найдите:
```javascript
let slideInterval = setInterval(nextSlide, 5000); // 5000ms = 5 секунд
```

### Добавить новый товар
Откройте `index.html` и скопируйте блок:
```html
<div class="product-card">
    <!-- Содержимое карточки -->
</div>
```

## 🐛 Устранение проблем

### Проблема: Стили не применяются
**Решение**: 
- Убедитесь, что `styles.css` в той же папке
- Проверьте путь в `<link>` теге
- Очистите кеш браузера (`Ctrl+Shift+R`)

### Проблема: JavaScript не работает
**Решение**:
- Убедитесь, что `script.js` в той же папке
- Откройте консоль браузера (`F12` → Console)
- Проверьте наличие ошибок

### Проблема: Изображения не загружаются
**Решение**:
- Проверьте интернет-соединение
- URL изображений используют Unsplash (требуется интернет)
- Замените на локальные изображения при необходимости

### Проблема: Порт 8000 занят
**Решение**:
```bash
# Используйте другой порт
python -m http.server 8080
# или
python -m http.server 3000
```
