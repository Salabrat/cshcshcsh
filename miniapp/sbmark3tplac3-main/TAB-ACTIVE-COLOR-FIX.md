# ✅ Исправление цвета активной вкладки

## Что исправлено

Добавлен `!important` к стилям активной вкладки для гарантированного применения белого текста на черном фоне.

---

## 📝 CSS Изменения

### Раньше:
```css
.mega-menu-tab.active {
    background-color: #000;
    color: #fff;
}
```

### Теперь:
```css
.mega-menu-tab.active {
    background-color: #000 !important;
    color: #fff !important;
}
```

**Почему добавлен !important:**
- Гарантирует применение стилей
- Переопределяет любые другие правила
- Обеспечивает белый текст на черном фоне

---

## 🎨 Цветовая схема

### Активная вкладка (MAIN COLLECTION):
- **Фон:** `#000` (черный) ⚫
- **Текст:** `#fff` (белый) ⚪
- **Разделитель "+":** `#fff` (белый)

### Неактивная вкладка (BRAND):
- **Фон:** `#fff` (белый) ⚪
- **Текст:** `#000` (черный) ⚫
- **Разделитель "+":** `#000` (черный)

---

## 🔄 Что делать

### 1. Очистите кэш:
```
Ctrl + Shift + Delete
```

### 2. Перезагрузите:
```
Ctrl + Shift + R
```

### 3. Проверьте:
- Откройте SHOP mega menu
- Активная вкладка: черный фон + белый текст ✅
- Неактивная вкладка: белый фон + черный текст ✅

---

## 🎉 Готово!

Активная вкладка теперь гарантированно имеет **белый текст на черном фоне**!
