# Руководство по редактированию изображений для администратора

## Обзор
Система позволяет администраторам изменять изображения на главной странице сайта через удобный интерфейс с кнопками редактирования.

## Функциональность

### Для администраторов:
- **Кнопки редактирования** - появляются при наведении на изображения
- **Расположение кнопки** - правый нижний угол изображения
- **Текст кнопки** - "📷 Изменить фото"
- **Цвет кнопки** - красный (rgba(220, 38, 38, 0.9))

### Редактируемые изображения:
1. **Hero секция** - главное изображение на странице
2. **Campaign 1** - первая кампания
3. **Campaign 2** - вторая кампания  
4. **Campaign 3** - третья кампания
5. **About 1** - первое изображение в секции "О компании"
6. **About 2** - второе изображение в секции "О компании"

## Как использовать

### Шаг 1: Войти как администратор
```javascript
// В консоли браузера:
localStorage.setItem('adminLoggedIn', 'true');
localStorage.setItem('username', 'admin');
location.reload();
```

### Шаг 2: Навести курсор на изображение
- При наведении появится красная кнопка "📷 Изменить фото"

### Шаг 3: Нажать на кнопку редактирования
- Откроется модальное окно с опциями загрузки

### Шаг 4: Выбрать новое изображение
Два способа:
1. **Загрузить файл с компьютера** - нажать на область "Выбрать файл с компьютера"
2. **Указать URL изображения** - ввести ссылку в поле URL

### Шаг 5: Сохранить изменения
- Нажать кнопку "Сохранить"
- Изображение автоматически обновится на странице
- Появится уведомление об успешном сохранении

## Технические детали

### Файлы системы:
- `homepage-image-editor.js` - основной скрипт редактирования (только для админов)
- `load-homepage-images.js` - загрузка сохраненных изображений для всех пользователей
- `homepage-images.json` - хранилище URL изображений

### API endpoints:
- `GET /api/homepage-images` - получить текущие изображения
- `POST /api/homepage-images` - сохранить новые изображения
- `POST /api/upload` - загрузить файл изображения

### Проверка администратора:
```javascript
function isAdmin() {
    return localStorage.getItem('adminLoggedIn') === 'true' || 
           localStorage.getItem('username') === 'admin' ||
           localStorage.getItem('userRole') === 'admin';
}
```

### Структура данных (homepage-images.json):
```json
{
  "hero": "URL изображения hero секции",
  "campaign1": "URL первой кампании",
  "campaign2": "URL второй кампании",
  "campaign3": "URL третьей кампании",
  "about1": "URL первого изображения о компании",
  "about2": "URL второго изображения о компании"
}
```

## Особенности

### Визуальные эффекты:
- Кнопки появляются плавно при наведении
- Анимация масштабирования при наведении на кнопку
- Модальное окно с анимацией появления
- Уведомления с анимацией slide-in/slide-out

### Безопасность:
- Кнопки редактирования видны только администраторам
- Проверка прав при каждой инициализации
- Валидация типов файлов (только изображения)

### Удобство использования:
- Предпросмотр изображения перед сохранением
- Возможность отмены действия
- Закрытие модального окна по Escape или клику вне окна
- Автоматическая загрузка сохраненных изображений

## Решение проблем

### Кнопки не появляются:
1. Проверить статус администратора в localStorage
2. Обновить страницу
3. Проверить консоль на ошибки

### Изображения не сохраняются:
1. Проверить работу сервера (порт 3002)
2. Проверить права на папку uploads
3. Проверить размер файла (максимум 10MB)

### Изображения не загружаются:
1. Проверить файл homepage-images.json
2. Проверить доступность URL изображений
3. Проверить работу API endpoint

## Быстрый тест

1. Открыть консоль браузера (F12)
2. Выполнить команды:
```javascript
// Включить режим администратора
localStorage.setItem('adminLoggedIn', 'true');
localStorage.setItem('username', 'admin');

// Перезагрузить страницу
location.reload();

// Проверить инициализацию
console.log('Image editor initialized:', !!window.homepageImageEditor);
```

3. Навести курсор на любое изображение главной страницы
4. Должна появиться красная кнопка "📷 Изменить фото"
