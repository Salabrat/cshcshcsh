# 🔧 Решение ошибки ERR_NGROK_727

## ❌ Проблема
Ошибка `ERR_NGROK_727: HTTP Requests exceeded` означает, что ваш бесплатный аккаунт ngrok превысил лимит HTTP-запросов.

## ✅ Быстрое решение: Cloudflare Tunnel (БЕСПЛАТНО, без лимитов)

### Шаг 1: Установите Cloudflare Tunnel

**Windows:**
1. Скачайте `cloudflared.exe` с https://github.com/cloudflare/cloudflared/releases/latest
2. Распакуйте в папку проекта или добавьте в PATH

**Или через npm:**
```bash
npm install -g cloudflared
```

### Шаг 2: Запустите сервер и туннель

**Вариант 1: Автоматический (рекомендуется)**
```bash
# Просто запустите bat-файл:
start-cloudflare.bat
```

**Вариант 2: Вручную**
```bash
# Терминал 1 - Запустите сервер:
npm start

# Терминал 2 - Запустите туннель:
npm run tunnel
# или
cloudflared tunnel --url http://localhost:3002
```

### Шаг 3: Скопируйте URL

После запуска вы увидите что-то вроде:
```
+--------------------------------------------------------------------------------------------+
|  Your quick Tunnel has been created! Visit it at:                                         |
|  https://random-name-1234.trycloudflare.com                                               |
+--------------------------------------------------------------------------------------------+
```

### Шаг 4: Обновите URL в BotFather

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/mybots`
3. Выберите вашего бота
4. Выберите "Bot Settings" → "Menu Button"
5. Введите новый URL: `https://ваш-url.trycloudflare.com/TGminiapp.html`
6. Сохраните

## 🔄 Другие решения

### Решение 2: Обновить план ngrok (Платно)

1. Перейдите на https://dashboard.ngrok.com/billing
2. Обновите план до **Starter** ($8/месяц)
3. Получите больше лимитов

### Решение 3: Подождать сброса лимита

Бесплатный план ngrok сбрасывает лимиты:
- **Раз в месяц** (обычно 1-го числа)
- Или через **24 часа** после превышения

### Решение 4: Использовать localtunnel

```bash
# Установите:
npm install -g localtunnel

# Запустите:
lt --port 3002
```

## 📊 Сравнение решений

| Решение | Стоимость | Лимиты | Рекомендация |
|---------|-----------|--------|--------------|
| **Cloudflare Tunnel** | Бесплатно | Нет | ⭐ Лучший выбор |
| **localtunnel** | Бесплатно | Есть, но больше | ✅ Хорошо |
| **ngrok (платный)** | $8/месяц | Больше | 💰 Если нужен ngrok |
| **ngrok (бесплатный)** | Бесплатно | Мало | ❌ Лимиты |

## 🚀 Рекомендация

**Используйте Cloudflare Tunnel** - это бесплатно, без лимитов, и работает так же хорошо, как ngrok!

Просто запустите:
```bash
start-cloudflare.bat
```

Или вручную:
```bash
npm start
# В другом терминале:
npm run tunnel
```

---

## ⚠️ Важно

- Cloudflare Tunnel URL меняется при каждом перезапуске (как и бесплатный ngrok)
- После перезапуска обновите URL в BotFather
- Для продакшена используйте реальный домен с HTTPS
