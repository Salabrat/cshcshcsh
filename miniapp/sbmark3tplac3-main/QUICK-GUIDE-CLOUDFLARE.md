# ⚡ Быстрая инструкция: Что делать дальше

## 🎯 Ваша ситуация

Вы запустили `npm run cloudflare` и видите:
```
📡 Starting Cloudflare Tunnel...
Installed cloudflared to ...
```

## ⏳ Шаг 1: ПОДОЖДИТЕ 5-10 секунд

Cloudflare Tunnel создает туннель. **Подождите**, и в консоли появится:

```
============================================================
✅ CLOUDFLARE TUNNEL READY!
============================================================

📱 Mini App URL для BotFather:

   https://random-name-1234.trycloudflare.com/TGminiapp.html

📋 Скопируйте этот URL и отправьте BotFather
============================================================

💾 URL сохранен в файл: cloudflare-url.txt
```

## 📋 Шаг 2: Скопируйте URL

Скопируйте URL из консоли (например: `https://random-name-1234.trycloudflare.com/TGminiapp.html`)

**ИЛИ** откройте файл `cloudflare-url.txt` в папке проекта - там будет сохранен URL.

## 📱 Шаг 3: Обновите в BotFather

1. Откройте Telegram → [@BotFather](https://t.me/BotFather)
2. Отправьте: `/mybots`
3. Выберите вашего бота
4. Выберите "Bot Settings" → "Menu Button"
5. Вставьте скопированный URL
6. Готово! ✅

## 🔍 Если URL не появился

1. **Подождите еще 10-15 секунд** - туннелю нужно время
2. **Проверьте файл** `cloudflare-url.txt` в папке проекта
3. **Посмотрите в консоли** - URL может быть в другом месте вывода

## ⚠️ Важно

- **НЕ закрывайте консоль** - сервер и туннель должны работать
- URL меняется при каждом перезапуске
- После перезапуска обновите URL в BotFather
