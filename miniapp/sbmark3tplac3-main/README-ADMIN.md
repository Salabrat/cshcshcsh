# Инструкция для администратора

## Как войти в режим администратора

### Способ 1: Через страницу входа (рекомендуется)
1. **Перейдите на страницу входа:** `admin-login.html`
2. **Или нажмите на иконку щита** в правом верхнем углу любой страницы
3. **Введите данные для входа:**
   - Email: `admin@admin.ru`
   - Пароль: `admin`
4. **Нажмите "ВОЙТИ"**
5. **После успешного входа вы будете перенаправлены на страницу категорий с активированным режимом администратора**

### Способ 2: Быстрый доступ (резервный)
1. **Откройте любую страницу категории** (например, `category-jackets.html`)
2. **Нажмите комбинацию клавиш: `Ctrl + Alt + A`**
3. **Введите пароль администратора: `admin123`**

### Индикаторы активного режима администратора:
- ✅ Красный индикатор "👑 ADMIN MODE ВЫЙТИ" в левом верхнем углу
- ✅ Зеленые кнопки "Добавить товар" на всех страницах категорий

## Как добавить товар

1. **Включите режим администратора** (см. выше)
2. **Перейдите на страницу нужной категории:**
   - `category-jackets.html` - для курток
   - `category-shoes.html` - для обуви  
   - `category-coats.html` - для пальто
   - `category-sweaters.html` - для кофт
   - `category-glasses.html` - для очков
   - `category-pants.html` - для штанов
   - `category-hats.html` - для головных уборов

3. **Нажмите зеленую кнопку "Добавить товар"**

4. **Заполните форму:**
   - **Название товара** - обязательное поле
   - **Описание** - обязательное поле  
   - **Размеры** - выберите доступные размеры (XS, S, M, L, XL, XXL, XXXL)
   - **Цена** - укажите цену в рублях
   - **Фотографии** - загрузите до 10 фото (PNG, JPEG, до 5MB каждое)

5. **Нажмите "Сохранить товар"**

## Что происходит после добавления товара

- ✅ Товар появляется на текущей странице категории
- ✅ Товар автоматически добавляется в каталог "SHOP ALL"
- ✅ Обновляется счетчик товаров в категории
- ✅ При клике на товар открывается детальная страница

## Страница товара

- **Левая часть** - прокручиваемая галерея фотографий
- **Правая часть** - фиксированная информация о товаре
- **Размеры** - интерактивный выбор размера
- **Секции** - раскрывающиеся блоки с информацией

## Выход из режима администратора

- **Нажмите "ВЫЙТИ"** в красном индикаторе "👑 ADMIN MODE ВЫЙТИ" в левом верхнем углу
- **Подтвердите выход** в диалоговом окне
- **Вы будете перенаправлены на страницу входа**

### Альтернативный способ:
- **Нажмите `Ctrl + Alt + A`** для быстрого переключения режима

## Технические детали

- Товары сохраняются в `localStorage` браузера
- Для реального использования нужно подключить backend
- Пароль администратора: `admin123` (в продакшене должен быть изменен)
- Поддерживаются форматы изображений: PNG, JPEG, JPG
- Максимальный размер изображения: 5MB
- Максимальное количество изображений: 10 штук

## Структура файлов

- `product-manager.js` - основная логика управления товарами
- `product-page.js` - логика страницы товара  
- `product.html` - шаблон страницы товара
- `styles.css` - стили для всех компонентов
