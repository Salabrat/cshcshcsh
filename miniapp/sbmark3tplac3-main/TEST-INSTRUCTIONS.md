# Инструкция по тестированию системы

## 🔐 Вход в админку

1. Откройте сайт в браузере
2. Нажмите на иконку входа (человечек) в правом верхнем углу
3. Введите админские данные:
   - Email: `admin@admin.ru`
   - Пароль: `admin`
4. После входа вы будете перенаправлены на главную страницу
5. Перейдите в любую категорию товаров (например, КУРТКИ)
6. Вы должны увидеть кнопку "Добавить товар" вверху страницы

## ➕ Добавление товара

1. Нажмите кнопку "Добавить товар" на странице категории
2. Заполните форму:
   - Название товара
   - Описание
   - Цена (только число)
   - Выберите размеры (кликните на нужные)
   - Загрузите изображения (можно несколько)
3. Нажмите "Сохранить товар"
4. Товар появится на странице категории

## 👁️ Просмотр товара

1. Кликните на любой товар в каталоге
2. Откроется модальное окно с:
   - Фотографиями товара (листайте стрелками или свайпом на мобильном)
   - Названием и ценой
   - Размерами
   - Описанием (разворачивается по клику)
   - Дополнительной информацией в складывающихся секциях
3. Закройте окно кликом на крестик, Escape или клик вне окна

## 🗑️ Очистка тестовых данных

В консоли браузера (F12 → Console) можно выполнить:
- `clearAllProducts()` - удалить все товары (с подтверждением)
- `removeProductByName("название")` - удалить конкретный товар

## ⚠️ Важно

- Товары сохраняются в localStorage браузера
- Товары видны всем пользователям (не только админам)
- При очистке кэша браузера товары удалятся
- Админ-панель появляется только после авторизации админа

## 🐛 Диагностика проблем

Если что-то не работает, проверьте консоль браузера (F12):
1. Есть ли ошибки JavaScript
2. Загрузились ли все скрипты
3. Есть ли сообщения о загрузке базы данных
