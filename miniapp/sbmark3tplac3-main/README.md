# C.P. Company - Pixel Perfect Clone

Точная копия главной страницы официального сайта C.P. Company (https://www.cpcompany.com/ru-ru/)

## 🎨 Особенности

### Визуальное соответствие
- ✅ Pixel-perfect дизайн с точным соответствием оригиналу
- ✅ Идентичные шрифты, цвета и spacing
- ✅ Современный минималистичный интерфейс
- ✅ Профессиональная типографика

### Функциональность
- ✅ Полнофункциональный header с навигацией
- ✅ Интерактивное мега-меню с подкатегориями
- ✅ Hero-слайдер с автопрокруткой
- ✅ Адаптивная сетка товаров
- ✅ Hover-эффекты на карточках товаров
- ✅ Функциональный поиск
- ✅ Форма подписки на рассылку
- ✅ Интеграция с социальными сетями

### Интерактивность
- ✅ Плавные анимации и переходы
- ✅ Автоматическая прокрутка слайдера (каждые 5 секунд)
- ✅ Навигация слайдера: кнопки, точки, клавиатура, свайпы
- ✅ Смена изображений товаров при наведении
- ✅ Добавление в избранное
- ✅ Быстрый просмотр товара
- ✅ Overlay поиск
- ✅ Система уведомлений
- ✅ Lazy loading изображений
- ✅ Scroll animations

### Адаптивность
- ✅ Desktop (1920px+)
- ✅ Laptop (1024px+)
- ✅ Tablet (768px+)
- ✅ Mobile (320px+)
- ✅ Мобильное меню с бургер-иконкой
- ✅ Touch-gestures для слайдера

## 🚀 Быстрый старт

### Установка
1. Скачайте все файлы проекта
2. Откройте `index.html` в браузере

Вот и всё! Никаких зависимостей или сборки не требуется.

## 🎯 Основные блоки

### 1. Top Bar
- Ссылка на Massimo Osti Studio
- Выбор языка (RU/ru)
- Ссылка на вход/регистрацию

### 2. Header
- Логотип C.P. Company
- Горизонтальное меню навигации
- Мега-меню с подкатегориями и изображениями
- Иконки: поиск, личный кабинет, избранное, корзина
- Мобильное меню (бургер)

### 3. Hero Slider
- Полноэкранные слайды с изображениями
- Текстовые наложения с CTA-кнопками
- Автопрокрутка каждые 5 секунд
- Навигация: стрелки, точки, клавиатура, свайпы
- Overlay градиент для читаемости текста

### 4. Featured Categories
- Сетка из 2 крупных карточек
- Hover-эффект с увеличением изображения
- Текстовые наложения

### 5. Products Grid
- Сетка 4x1 товаров (адаптивная)
- Смена изображения при hover
- Кнопки действий при hover
- Информация о товаре: категория, название, цена

### 6. Footer
- Форма подписки на рассылку
- Колонки с ссылками
- Социальные сети
- Способы оплаты
- Копирайт

## 🎨 Особенности дизайна

### Анимации
- **fadeInUp** - Появление элементов слайдера
- **slideIn/slideOut** - Уведомления
- **Smooth transitions** - 0.3s ease для всех hover-эффектов
- **Scale hover** - 1.05 для изображений
- **Transform animations** - Плавные появления элементов при скролле

### Hover-эффекты
- Подчеркивание навигационных ссылок
- Смена изображений товаров
- Появление кнопок действий
- Увеличение изображений категорий
- Изменение цвета иконок

### Типографика
- **Headings**: 700 weight, uppercase, letter-spacing
- **Body**: 400 weight, line-height 1.6
- **Links**: 500 weight, uppercase для навигации
- **Buttons**: 600 weight, uppercase, letter-spacing
