# Запуск Бота + Mini App

## 🚀 Быстрый запуск

### Вариант 1: BAT файл (рекомендуется)
Дважды кликните на `start_all.bat`

### Вариант 2: PowerShell
Правый клик на `start_all.ps1` -> "Запустить с помощью PowerShell"

## 📋 Что происходит при запуске:

1. **Запускается Node.js сервер** для Mini App (порт 3000)
2. **Запускается localtunnel** для внешнего доступа к Mini App
3. **Запускается Telegram бот** (`streetshop.py`)

Все сервисы работают в отдельных окнах.

## 🔧 Первичная настройка:

### 1. Запустите `start_all.bat`

### 2. Дождитесь запуска всех сервисов (около 10 секунд)

### 3. В окне "LocalTunnel" скопируйте URL
   (выглядит как `https://something.loca.lt`)

### 4. Обновите `config.py`:
```python
MINIAPP_URL = "https://something.loca.lt/TGMiniapp.html"
```

### 5. Перезапустите бот:
   - Закройте окно "Telegram Bot"
   - Запустите `start_all.bat` снова

## 🎯 После настройки:

Теперь при каждом запуске `start_all.bat` будет автоматически:
- Запускаться сервер Mini App
- Создаваться туннель для доступа
- Запускаться бот с рабочей кнопкой "📱 Открыть приложение"

## 📱 Проверка:

1. В Telegram откройте бота
2. Нажмите кнопку "📱 Открыть приложение" (в самом верху)
3. Mini App должна открыться с полным дизайном

## ⚠️ Важно:

- localtunnel каждый раз может выдавать новый URL
- Если URL изменился - обновите config.py и перезапустите бот
- Все 3 окна должны быть открыты для нормальной работы
